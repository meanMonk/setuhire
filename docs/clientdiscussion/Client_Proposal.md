## 1. Overview

SetuHire (codename, TBD) is a purpose-built platform for IT staffing / bench-sales teams to manage clients, vendors, candidates, job requirements, and placements in one place — replacing scattered email threads and spreadsheets with a searchable, trackable system.

This proposal covers the scope, timeline, and cost for delivering a working v1, based on the demo already reviewed together.

---

## 2. Problems We're Solving

| Today | With SetuHire |
|---|---|
| Recruiters manually screen hundreds of resumes per requirement | AI-assisted ranked matching surfaces a pre-filtered shortlist |
| Resumes sit as unsearchable PDFs/Word files | Structured, searchable candidate profiles |
| Match quality depends on which recruiter picks up the requirement | Consistent, ranked fit scores for every requirement |
| Founders/managers chase recruiters for pipeline status | Live role-based dashboards — funnel visible without asking |
| Margin per job is reconciled manually, after the fact | Billing vs cost vs margin visible per job, in real time |

*Note: automated candidate-facing communication (auto emails/SMS on status change) is not in this scope — flagged separately if needed, see Section 6 (Exclusions).*

---

## 3. Scope of Work

| Module | What it does |
|---|---|
| **Client Management** | Client profiles, engagement history, jobs raised per client, pricing view (billing rate vs cost vs margin) per active job |
| **Vendor Management** | Vendor profiles, performance stats (submissions, shortlists, placements), resources supplied |
| **Candidate / Resource Management** | Structured candidate profiles, resume upload & parsing, availability status |
| **Job / Requirement Management** | Job intake (via URL or manual entry), AI-assisted matching of candidates to requirements with ranked fit scores |
| **Role-Based Dashboards** | Separate views for Admin, Sales, and Manager roles — each scoped to what they need to see |
| **Finance & Reporting** | Billing vs payout vs margin tracking, with visibility controls for sensitive financial data |

Anything beyond these six modules — new features, integrations, or workflow changes not listed above — will be scoped and quoted separately as a change request, so the delivery timeline and cost below stay fixed.
